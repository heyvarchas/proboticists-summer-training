# Autonomous Subsystem

This directory contains projects related to the development of autonomous robotic capabilities. The projects focus on enabling robots to perceive their environment, process information, and perform tasks with minimal human intervention.

---

## Overview

The autonomous subsystem serves as a collection of independent projects exploring various aspects of robot autonomy, including computer vision, perception, localization, navigation, and decision-making.

Each project is developed as a self-contained module and may use different tools, libraries, and implementation approaches depending on its objectives.

---

## Repository Structure

The autonomous subsystem is organized into project-specific folders. Each project maintains its own source code, documentation, assets, and demonstrations.

Example:

```
autonomous_subsystem/
├── project_1/
│   ├── README.md
│   ├── source_code/
│   └── assets/
├── project_2/
│   ├── README.md
│   ├── notebooks/
│   └── results/
└── ...
```

---

## Current Projects

### YOLO-Aruco Object Centering

A computer vision project that combines YOLO-based object detection with ArUco marker detection to determine and compare object and marker positions within the camera frame. The project demonstrates techniques commonly used in autonomous targeting, localization, and visual servoing applications.

---

## Project Documentation

Each project folder contains its own documentation, including:

* Project objectives
* Implementation details
* Dependencies and setup instructions
* Usage guidelines
* Demonstration results
* References and resources

For detailed information, refer to the README file within the respective project directory.

---

## Design Philosophy

Since autonomous robotics projects often vary significantly in scope and implementation, this directory does not enforce a rigid folder structure. Projects are organized independently to allow flexibility while maintaining clear documentation and reproducibility.

---

## Purpose

The goal of this directory is to maintain a structured collection of autonomous robotics projects developed during training, experimentation, and research, while ensuring that each project remains independently understandable and reproducible.
